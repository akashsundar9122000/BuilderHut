## Preview

Preview saves the draft first, then opens it in a new tab. That order matters: what you look at
is what is **stored**, not what happened to be on screen — so if the two ever disagreed, preview
would show you the disagreement rather than hide it.

What you get is the shop as a customer would get it. No outlines, no panels, links between
pages working. The band across the top is the only thing that is not the shop.

## Publishing

![The publish panel, listing what is ready and what is not before anything goes public.](shot:publish-readiness "Blockers stop a publish. Warnings and suggestions do not.")

Publishing checks the shop is fit to open before it opens it.

| | Stops a publish | Example |
|---|---|---|
| **Blocker** | Yes | No delivery option, so the checkout cannot complete |
| **Warning** | No | A product with no picture |
| **Suggestion** | No | No description on the home page for search engines |

A shop with no delivery option has a checkout nobody can finish. Letting that go live would
mean finding out from a customer, so it says so instead.

:::warning
Blockers are about whether the shop can take an order, not whether it looks finished. A shop
can publish with placeholder words still in it — that is a warning, not a blocker, because only
you know whether they are placeholders.
:::

## Going back

Every publish is kept as a version — an exact snapshot, not a summary of what changed. Going
back is choosing an earlier one, which copies it into your draft for you to look at before you
publish it again.

:::note
Restoring puts the old version into the **draft**, not straight onto the live shop. So you can
restore something from last month, look at it, change your mind, and the public never saw
either.
:::

:::faq
### Can I unpublish?

Yes. The shop's address then shows that it is not currently open, rather than disappearing.

### Does publishing change my web address?

No. The address is set once and stays.

### How long does it take to appear?

Immediately. There is no build step and nothing to wait for.
:::

Two different tools, often confused:

- A **compare-at price** is a visible sale. The old price is struck through, the percentage is
  worked out for you, and everybody gets it. See [adding what you sell](/guide/selling/your-products).
- A **discount code** is typed at checkout. Only people who have it get it.

Use the first for a sale. Use the second for a specific group — a market you did, a collaboration,
an apology for a late parcel.

## The three kinds

| Kind | Example |
|---|---|
| **Percent off** | `WINTER10` — 10% off the basket |
| **Fixed amount off** | `SORRY200` — ₹200 off |
| **Free delivery** | `FREEPOST` — postage removed |

## Limits worth setting

**An expiry.** Codes escape. A code printed on a flyer in March and still working in November is
a code somebody has posted to a deals site.

**A usage cap.** Especially for anything generous. "First 50 customers" is a promise you can
actually keep if the code stops at 50.

:::warning
A code with no expiry and no cap is permanent and unlimited. Deals sites index these
automatically, and a 25% code meant for twelve market customers can end up on every order you
take for a year.
:::

## Writing a code

Short, unambiguous, and unmistakable when read aloud.

:::tip
Avoid the characters people confuse — `0` and `O`, `1` and `l`. `KILN10` is fine. `KILN1O0` will
generate messages asking why it does not work.
:::

Codes are not case sensitive, so nobody has to get that right.

## What the customer sees

A box at the basket, and again at checkout. A code that does not apply says why — expired, used
up, or not a code — rather than silently doing nothing.

:::faq
### Can two codes be used together?

No. One per order, which is almost always what you meant.

### Does a code work with a compare-at price?

Yes, and it comes off the already-reduced price. Worth remembering before setting both at once.

### Can I see who used a code?

Redemptions are counted, and the code appears on the order it was used on.

### How do I stop a code immediately?

Switch it off. It stays in the list with its history rather than vanishing.
:::

Every shop gets an address the moment it is created. It works immediately, it is free, and it
keeps working forever — connecting your own domain adds one, it does not replace it.

## Using a domain you own

:::steps
### Add it here

Type the domain into the domains page. It is checked for obvious problems before anything else
happens.

### Add one DNS record

The page shows you exactly which record, with the exact value. You add it wherever you bought
the domain.

### Wait

DNS takes anywhere from a few minutes to a few hours to spread. The page checks and tells you
when it has.

### Make it the primary

Once verified, set it as primary. Your BuilderHut address then redirects to it.
:::

:::warning
The wait is genuinely out of anyone's hands. If the page says the record is not visible yet,
that is usually true rather than a fault — give it an hour before assuming something is wrong.
:::

## Why the redirect matters

Two addresses serving the same shop means search engines see two shops and split the credit
between them. Setting a primary makes every other address redirect to it, so there is one shop
with one address as far as anything outside is concerned.

## Buying a domain

Not from here, in this build. Buy it wherever you like — the DNS record is the same everywhere —
and point it at the shop.

:::faq
### Do I need a domain?

No. Plenty of shops run on the address they were given. A domain is worth it when you are
printing it on something.

### Can I use a subdomain?

Yes — `shop.yourname.com` works the same way as the bare domain.

### What happens to my BuilderHut address afterwards?

It keeps working and redirects to the primary domain, so an old link in somebody's messages
still arrives.

### Is HTTPS included?

Yes, issued automatically once the domain verifies. There is nothing to buy or renew.
:::

:::faq
### Run a sale

Set a compare-at price on the products you want to discount — the shop strikes the old figure
through and works out the percentage. For a code people type at checkout, use discounts instead.

### Refund part of an order

Open the order, choose refund, and type the amount. The box starts empty because partial is the
normal case — see [orders and refunds](/guide/running/orders).

### Hide a section without deleting it

Open **Layers** in the left panel and hide it there. It stays on the page, keeps its words, and
comes back when you unhide it. Useful for anything seasonal.

### Go back to how the shop looked last week

Version history in the builder's top bar. Choose the version, which copies it into your draft —
it does not go live until you publish it.

### Use my own web address

Settings, then domains. You point your domain at us with a DNS record, and the page shows you
exactly which one and whether it has taken effect yet. Your BuilderHut address keeps working.

### Let somebody else help

Invite them from the team page. They get their own account and their own password, and you can
see who changed what. Four roles, from owner down to staff.

### Change what my shop is called

Settings. The name and the web address are separate — changing the name does not move the shop.

### Stop taking orders for a while

Unpublish. The address stays yours and shows that the shop is not currently open, rather than
going blank.

### Get my photographs back out

The media library keeps everything you uploaded, at the size it was stored.
:::

## When something looks wrong

:::faq
### The dashboard is empty and I know I have data

Sign out and back in. If it persists, it is worth reporting rather than working around — an
empty dashboard usually means a session lost track of which shop it was looking at, and that is
a fault worth knowing about.

### A picture did not upload

Files are capped at 8 MB, and only real images are accepted — the file is checked by its
contents rather than its name, so something renamed to `.jpg` is refused. Try a smaller file, or
a different format.

### My changes are not showing on the shop

The shop shows the last **published** version. Changes in the builder live in a draft until you
publish them. Use Preview to see the draft.

### The six-digit code never arrived

Spam folder first, then ask for another. See [making an account](/guide/start/signing-up).
:::
